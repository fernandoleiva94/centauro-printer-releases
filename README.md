# Centauro Printer - releases

Instalador del agente local de impresión de Centauro POS para Windows.

**Descarga:** [CentauroPrinter-Setup.exe](https://github.com/fernandoleiva94/centauro-printer-releases/releases/latest/download/CentauroPrinter-Setup.exe)

## Instalación

1. Descargá el instalador. Chrome o Edge pueden avisar que "no se descarga habitualmente": elegí **Conservar**.
2. Abrilo. Si Windows muestra "Windows protegió su PC", tocá **Más información** y después **Ejecutar de todas formas**.
3. Esperá a que termine. No pide permisos de administrador y no hace falta instalar Java.
4. Volvé a Centauro POS: el sistema detecta el agente solo.

El agente se instala para tu usuario de Windows, arranca solo al iniciar sesión y usa las impresoras
que ya tengas instaladas en el equipo.
